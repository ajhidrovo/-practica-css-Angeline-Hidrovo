# Delicias Gourmet

## Descripción
Sitio web desarrollado como parte de la práctica 3
"Aplicación de estilos y propiedades CSS".

El proyecto presenta un restaurante de comida gourmet,
sus servicios, menú, promociones y medios de contacto.

## Tecnologías utilizadas
- HTML5
- CSS3
- Visual Studio Code
- Git
- GitHub

## Funcionalidades
- Página de inicio.
- Presentación del restaurante.
- Menú con precios.
- Servicios del restaurante.
- Galería de seis imágenes.
- Enlaces externos e internos.
- Imágenes con enlaces.
- Formulario de contacto.
- Promociones especiales.

## Estructura del proyecto
- index.html
- css/styles.css
- imagenes/
- README.md
